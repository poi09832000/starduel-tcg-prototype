# 憶術之源 Origin of Memorycraft

以艾爾德隆（Eldelande）為舞台的集換式卡牌桌遊原型。玩家扮演年輕的憶術師本人。

## 專案資料

- [世界觀 V1.0](WORLD-V1.0.md)：創作者提供的九章設定，為目前世界觀基準。
- [遊戲規則與待定事項](RULES.md)：分別記錄已確認規則與原型示例。
- [更新紀錄](CHANGELOG.md)。
- [HTML 原型](index.html)：下載整個儲存庫後，以瀏覽器開啟；請保留 assets 資料夾相對位置。GitHub 檔案頁顯示原始碼，尚未部署成線上遊戲網站。
- [卡圖素材](assets/card-art-sheet.png)：英雄、裝備、物品共用的三格概念圖。
- [卡圖生成紀錄](ARTWORK.md)。

## 使用新版 v0.2

1. 下載完整儲存庫並解壓，保留 `index.html` 與 `assets` 的相對位置，再用瀏覽器開啟 `index.html`。不需要安裝套件。
2. 桌外猜拳，記錄勝方及其先後攻選擇，使用兩副各 20 張的測試牌組。
3. 按提示檢查起手、重抽及可選補抽；各選一張英雄蓋放，確認後同時翻面。
4. 開始階段補行動至上限並抽牌，再進主要階段。點手牌／模式按鈕與戰場格操作；結束階段處理完效果後交接。
5. 裝備與技能需勾選雙方確認；技能／物品／階段效果以手動 HP 結算，未定的效果不自動推定。

本版為雙人共用螢幕測試，交接有手牌遮罩；不是連線遊戲，重新整理會重開。尚未部署線上網站，GitHub 檔案頁只顯示程式碼。

已接上目前確認的核心規則，移除舊版虛構的前後排數值加成。十種卡名、HP 4 與卡圖是測試素材，尚非正式卡片；目前卡池僅容許各兩張組成 20 張。卡牌效果與例外仍待提供，遇到牌組耗盡、同時敗北或例外裁定時會暫停。詳見 [實作狀態與限制](RULES.md)。

## 驗證

在儲存庫根目錄執行 `node rules.test.cjs`，不需額外套件。17 項測試涵蓋牌組、重抽、部署、行動補充與消耗、移動、裝備、物品、技能、退場、階段與敗北。另已於瀏覽器操作驗證從起手準備至無英雄判輸。

## 後續更新

以 GitHub main 分支最新資料為唯一更新基準。未來直接更新 GitHub 資料，每次變更建立新提交，保留所有歷史紀錄；不使用 force push 或改寫歷史。如需修正，以新的修正提交處理。開始更新前先讀取遠端最新版本，避免用過期本機檔案覆蓋後續變更。

世界觀調整時保留 V1.0，新增相應版本並更新此處的基準版本連結。規則調整寫入 RULES.md，實作變更與未完成事項寫入 CHANGELOG.md。網頁與卡圖分開保存，方便逐步替換。
